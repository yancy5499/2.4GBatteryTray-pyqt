2.4G 电量助手 (PyQt6) v2.0.0
================================

双击 2.4GBatteryTray.exe 即可运行，不需要安装 Python 或其他运行时。

请保持 exe 与 _internal 文件夹在一起；整个文件夹可以放到任意位置。

功能
----
- 每台 2.4G 设备一个托盘图标，图标用填充色表示剩余电量
- 未读取到电量的设备默认不显示托盘图标；设备卡片 ... 菜单可逐台开关
- 正常（≥50%）、偏低（<50%）、不足（<20%）三档提醒色可分别设置
- 耳机图标头梁为镂空圆环，填充按整个耳机高度计算，低电量保持白色
- 单次扫描 10–60 秒可调；自动扫描间隔 3 分钟 / 10 分钟 / 30 分钟 /
  1 小时 / 3 小时
- 电量历史：每次成功监听追加到每台设备唯一的 log\*.csv，支持 1 小时
  （24h）/ 1 天（最近一个月）曲线、逐台显示筛选
- 设备卡片 ... 菜单可直接“查看电量记录”，只显示该设备
- 主界面：设备电量卡片、托盘预览、三档提醒色与效果预览
- 图标设置：鼠标 / 键盘 / 耳机 / 手柄在 100% / 50% / 20% 下的形态
- 关闭到托盘、开机自启、单实例运行

提示
----
- 设备休眠时按一下键盘或移动鼠标，再点“搜索设备”
- 如果厂商驱动独占 HID，先关闭驱动软件
- 新托盘图标可能被 Windows 收进溢出区（^），可在任务栏设置中开启
- 受限终端 / 沙箱环境可能拒绝托盘图标；程序会提示并保持窗口显示

数据
----
设置、日志直接保存在 exe 所在的目录（便携模式）：
  settings.json   自动扫描间隔、单次扫描时长、三档颜色、窗口位置等
  app.log         运行日志
  log\*.csv       每台设备唯一的电量历史
如果 exe 目录不可写（例如放在 Program Files），会自动回退到
%APPDATA%\2.4GBatteryTray\。
